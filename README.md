 ReachyGrade is a fully functional web application that handles assignment creation, student submission, AI-powered grading, and grade management. The system supports three user roles with appropriate access controls, and the interface is clean, responsive, and easy to use.

## 👥 User Roles & Features

### 🎓 Student Features
* **Secure Login / Registration:** Easy access to the student dashboard.
* **Assignment Submission:** Upload assignments directly through the interface.
* **View Results:** Access automated grading feedback and scores instantly.

### 👩‍🏫 Teacher Features
* **Teacher Login:** Dedicated access to course management panels.
* **Assignment Creation:** Set up new assignments and grading rubrics.
* **Grade Management:** Review AI-generated grades and override scores if necessary.

### ⚙️ Admin Features
* **Admin Login:** Full dashboard access for system maintenance.
* **User Management:** Manage, approve, or restrict student and teacher accounts.
* **System Monitoring:** Oversee platform activity and database records.
